# Console-based C++ Battleship Game 

This short project is a two-player Battleship game written in C++ intended for play in the Console/Terminal. Made in 2022.

Note: It is a local game, so the players must play on the same laptop.

## Downloading + Set up:
To download and play:
1. Ensure you have the C++ interpreter installed
2. Click Code > Download as zip
3. Unzip the file
4. Navigate to your terminal or command prompt and change your directory to the unzipped file's folder:
   ```
   cd {file path to folder}
   ```
5. Compile into executable
   ```
   g++ BattleshipV3.cpp -o battleship
   ```
6. Run the executable
